# Team Task Manager

This is a tool to manage team projects and tasks. It helps administrators and team members work together in one place.

You can try it out here: https://team-task-manager-rose.vercel.app/

The team task manager has some features.

* **Login and Signup:** You can create an account as an Administrator or a Team Member.

* **Projects:** Administrators can create projects for the team.

* **Tasks:** Administrators can assign tasks to any team member.

* **Chat:** There is a chat box for every task to discuss work.

* **Status Tracking:** Team members can say when they finish work and Administrators can double-check the team task manager.

* **Dashboard:** A clean dashboard to see total projects and task progress in the team task manager.

To get started with the team task manager:

### 1. Backend:

You need to open the project folder for the team task manager.

Then you need to install the required libraries using `pip install -r requirements.txt` for the team task manager.

Next you need to run the server using `uvicorn main:app --reload` for the team task manager.

The backend will be active at http://127.0.0.1:8000 for the team task manager.

### 2. Frontend:

You need to go inside the frontend folder for the team task manager.

Then you need to run `npm install` to get everything for the team task manager.

Next you need to start the application using `npm run dev` for the team task manager.

You can see the team task manager app at http://localhost:5173.

The team task manager uses the following tech stack.

* **Backend:** FastAPI which uses Python
* **Frontend:** React which uses Vite
* **Database:** PostgreSQL
* **Design:** CSS and Icons
